## Validation

- Final root `bun run test`: passed, 90 files / 852 tests including the plugin SDK.
- Root `bun run typecheck` and `bun run build`: passed across the workspace. Build warnings remain for the Sentry JSON version import, Handlebars webpack loading, optional SSH native bindings and Node’s deprecated module registration API.
- Production Compose configuration validated with dummy secrets (`docker compose config --quiet`); no containers started.
- Changed TypeScript/JSON/Markdown/YAML files formatted with the installed Prettier; `git diff --check` passed.

- Web TypeScript and Vitest checks: passed; 43 files / 424 tests.
- GBX service TypeScript and Vitest checks: passed; 34 files / 323 tests.
- Shared TypeScript and Vitest checks: passed; 11 files / 91 tests.
- Prisma clients generated from both MySQL and PostgreSQL schemas; web and service typechecks checked against each generated client. Client restored to the configured provider afterward.
- Regression additions cover session-refresh failure, account tombstones, privilege preservation, delegated audit deletion, encryption round trips/tampering/plaintext rejection, service decryption, credential-bearing file requests, cancellation/redirects, dangerous paths/list filenames, resource IDs, read-only user lookups and mandatory mutation confirmation. Existing XSS/admin-input/HTTP egress tests were retained.
- Live OAuth, browser/game integration, database migration execution, cloud provisioning, reverse-proxy routing and production credential rotation require their documented infrastructure and were not executed here.

The account/session tests mock the database and provider; the crypto tests execute the real cipher and service adapter. They do not replace a restored-backup test of the migration. Existing open WebSockets retain the prior bounded lifetime; this change does not claim immediate socket revocation.
