## Information we process

Depending on the features you use, we process:

- **Account information:** your Trackmania account identifier, login, display name, Ubisoft identifier where available, and assigned roles, permissions, and group memberships. Sign-in takes place through Nadeo; you do not enter your Ubisoft password into this panel.
- **Player and match information:** player logins and nicknames, in-game location information where supplied by the server, race times, checkpoints, scores, match results, and player moderation information. Gameplay information can be processed even if you do not sign in to the panel.
- **Content and administration activity:** files and settings you submit, notifications, and audit records of management actions, including the account involved, action, time, and relevant details.
- **Technical information:** connection information, error reports, and service logs. Our hosting and network services may also process IP addresses, request details, and browser information.

## Optional features and external services

The following features depend on this installation's configuration:

- **Analytics:** if enabled, Plausible receives page-view and related usage information. Page addresses sent for analytics may include query parameters.
- **Error monitoring:** if enabled, Sentry receives diagnostic information and, depending on configuration, performance traces, application logs, and session replays.
- **AI assistant:** if Codriver is enabled and used, requests and relevant game or server context are sent to the configured AI services. The panel can store request text, replies, tool actions, feedback, and usage information.
